# Project Statement

## Problem Statement
Manual tracking of food intake can be inconsistent and difficult to organize. This project provides a simple local command-line system for profile management, calorie estimation, food logging, and daily summaries.

## Scope
- Profile management
- BMR and TDEE/reference calculations
- Food database
- Quantity-based calorie calculation
- Custom food entries
- Daily logging
- Daily summaries
- JSON persistence
- Validation
- Error handling
- Logging
- Unit testing

## Target Users
- Students learning Python
- Users wanting a simple local food log
- Students demonstrating software engineering practices
- Academic project evaluators

## High-Level Features
1. Profile Management
2. Calorie Calculation
3. Food Database
4. Food Logging
5. Daily Summary
6. Persistent Storage
7. Validation and Error Handling
8. Automated Testing

## Non-Functional Requirements
The application is modular, typed, locally persistent, testable, and designed without external runtime services.
